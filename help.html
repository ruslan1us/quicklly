Quicklly · Help

Press the hotkey anywhere, type a thought, press Enter: it is added with the time to a Markdown file in your notes folder.

Input window

Enter
save the note
Shift+Enter
new line
↑ ↓
previous / next saved note (in an empty field)
←
browse your notes in the reader
→
open the Pad for longer notes
Ctrl+E
move what you typed into the Pad
Ctrl+V
paste an image: saved in images/, shown as [Image #1] (also in the Pad)
?
search all notes
#
suggest your tags: ↑ ↓ choose, Enter or Tab pick (also in the Pad)
Esc, Ctrl+C
close

Commands

/config
settings
/pad
the Pad
/help
this help
/changelog
what's new in each version
/update
install a new version now
/exit
quit Quicklly

Tags

A note with a #tag goes to tag.md instead of the file of the day: buy milk #todo → todo.md.

Reader

Enter
open a file · edit a note
Tab
sort the files: recent first · by name
Shift+Enter
edit a note in the Pad
Space
mark a note done
C
copy a note's links
O
open a note's images
Del
move a file to the Recycle Bin · delete a note (press twice)
Ctrl+P
pin the open file: keep it on screen, up to date
← →
back to the files · back to the input

Pad

Ctrl+Enter
save as a note
Tab
indent (Shift+Tab: outdent)
Ctrl+P
pin: keep it open over other windows
←
back to the input (in an empty Pad)
