Quicklly · Help

Press the hotkey anywhere, type a thought, press Enter: it is added with the time to a Markdown file in your notes folder.

Input window

Enter
save the note
Shift+Enter
new line
↑ ↓
previous / next saved note (in an empty field)
←
browse your notes in the reader
→
open the Pad for longer notes
Ctrl+E
move what you typed into the Pad
Ctrl+V
paste an image: saved in images/, shown as [Image #1] (also in the Pad)
?
search all notes
#
suggest your tags: ↑ ↓ choose, Enter or Tab pick (also in the Pad)
/date
Enter opens a calendar to put a date in the note (also in the Pad)
Esc, Ctrl+C
close

Commands

/config
settings
/pad
the Pad
/help
this help
/changelog
what's new in each version
/reminders
the notes due today or earlier
/update
install a new version now
/exit
quit Quicklly

Tags

A note with a #tag goes to tag.md instead of the file of the day: buy milk #todo → todo.md. Nested tags go to folders: #work/quicklly → work/quicklly.md.

Dates

/date anywhere in a note, then Enter, opens a calendar; /date tomorrow or /date 15/10/2026 (in your date format) puts the date in straight away. Files keep it as 📅 2026-10-15, like Obsidian Tasks.

← →
previous / next day
↑ ↓
previous / next week
PgUp PgDn
previous / next month
Enter
pick the day
Esc
close the calendar, keep the text

Reminders

Notes that are not done and have a date of today or earlier pop up in the bottom right corner when Quicklly starts and when a new day begins, without taking the focus: click them to use the keys.

↑ ↓
select a note
Space
mark it done
Enter
open it in the reader
Esc
close

Archive

A note marked done gets the day, ✅ 2026-10-13; after 7 days (Archive done notes in /config) it moves to the same file in the archive folder, which the reader and the search leave out.
